    Spare disk

    Provide storage

    This device can keep data for others on this test network: it takes storage deals whose data it can fetch from the internet, keeps a copy, and proves every round that it still holds it; the client's escrow pays for each proven round, in test USD. Its collateral is at stake: a missed round costs part of it, an abandoned deal all of it. It takes short deals with modest collateral, never fetches from this machine or its local network for a stranger, and keeps proving the deals it holds when turned off. Best on a computer that stays on.

      Your agents

      The AI agents this device watches. Each one's standing is checked here as a light client checks it: its charter and those of every agent above it are proven against a certified header of the pinned chain, so a node cannot show a suspended agent as active. An agent this device backs can be suspended at once, with everything below it, and resumed or revoked later; the ledger refuses its payments while it is stopped.

      Finds the agents registered or spawned with this device as their backer, among the Pulses the node still keeps. Others can be added by id.
