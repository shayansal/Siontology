The source code is licensed under Apache-2.0 or MIT. Those licences let
you use, change and distribute the code. They do not grant any right to
use the Siontology name or logo (the Apache License says so in section 6).

## What you may do without asking

- **Refer to the project truthfully**: "built with Siontology", "a client
  for Siontology", "compatible with the Siontology HTTP API", "a fork of
  Siontology".
- **Distribute unmodified copies** of the code under the name Siontology.
- **Write about it**: articles, talks, tutorials, research papers and
  comparisons may use the name, and the logo to illustrate the project, as
  long as they do not suggest that ColdAI endorses them.

## What needs permission

- **Naming a modified version** Siontology, or anything confusingly
  similar. A fork or a modified distribution must use another name; it may
  say that it is based on Siontology.
- **Using the logo** for a product, service, network or modified version.
- **Using the name in a product, company, network or domain name**, or in a
  way that suggests ColdAI made, runs or endorses something it does not.
- **Selling merchandise** with the name or logo.

## Networks

Only networks that ColdAI operates or authorizes may call themselves
Siontology. Anyone may run the software; a network run by others should
use its own name and may say that it runs Siontology software.

## Asking

To ask for permission, or to report misuse, open an issue in the
repository or write to the maintainers listed in `.github/CODEOWNERS`.
